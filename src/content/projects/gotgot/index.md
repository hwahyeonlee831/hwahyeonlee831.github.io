> **한눈에**
> - **무엇:** 직접 확인한 서울의 장소를 싣고, 담아 둔 곳을 **하루 코스로 이어 주는** 서비스입니다. 광고도 별점도 없습니다.
> - **전환:** "일정을 짜 주는 AI"로 시작해 **저장한 곳을 다시 꺼내는 도구**로 중심을 옮겼습니다.
> - **방식:** 코드는 AI 에이전트가 쓰고, 저는 결정을 내렸습니다. **진단은 제보이지 명세가 아닙니다.**

## 1. What It Does

| 화면 | 하는 일 |
| --- | --- |
| **피드** | 동네·분류·시간대·동행·예산·대기로 거른다. 필터가 전부 링크라 뒤로 가기와 공유가 됨 |
| **저장 / 이번에 담기** | 나중을 위한 목록과 이번 외출 목록을 분리. 둘 다 **로그인 없이** |
| **하루 코스** | 담은 곳을 시간 순으로 배치. 블록을 끌어 시각을 바꾸고, 링크·캘린더·동선 지도로 내보냄 |

## 2. Four Turns — 방향을 바꾼 네 번

곳곳의 이야기는 기능을 더한 것보다 **중심을 옮긴 것**으로 요약됩니다.

| | 전 | 후 | 왜 |
| --- | --- | --- | --- |
| **제품** | 조건을 넣으면 일정을 짜 준다 | 저장한 곳을 **다시 꺼낸다** | 사람들은 저장만 하고 다시 열지 않음 |
| **지표** | 저장 수 | 2주 안에 **다시 꺼낸 비율** | 저장은 부풀리기 쉽고, 다시 꺼내는 일은 필요할 때만 일어남 |
| **코스 엔진** | 장소 → 거리 → 장소 | **하루 → 역할 → 장소 → 경로** | 가까운 순서로 이으면 "카페 → 식당 → 식당 → 카페"가 나옴 |
| **이름** | dagen (하루) | **곳곳** (곳) | 중심이 "하루"에서 "장소"로 옮겨 감 |

**코스 엔진에서 기억할 것**
- 사용자에게 묻는 건 **시작 시각 하나**입니다. 오후 2시에 시작하면 점심은 넣지 않습니다.
- "걸어서 3분"은 이유가 아니라 계산 결과입니다. **추천 이유는 역할로 씁니다.**
- 담은 곳은 **전부 앉힙니다.** 못 넣은 곳에는 휴무·시간 부족 같은 사실만 사유로 붙입니다.

**하지 않기로 한 것**

| 기각 | 이유 |
| --- | --- |
| 사용자 폴더 | 폴더는 저장할 때의 노동, 조건 칩은 꺼낼 때의 선택 |
| 저장에 로그인 요구 | 경쟁 상대는 SNS의 저장 버튼. 마찰 0인 상대에게 짐 |
| 자연어 LLM 입력창 | 받을 수 있는 조건이 얇으면, 대부분을 버리면서 다 알아들은 척하게 됨 |
| 도보 길찾기 API | 약관·제휴 조건. **코드 0줄**로 끝난 라운드 |

결정마다 "이 결정을 뒤집을 조건"을 함께 적었습니다. 같은 논의를 다시 하지 않게 됐습니다.

## 3. Design System — 규칙 세 개

| 규칙 | 내용 |
| --- | --- |
| **한글 문장, 영문 라벨** | 편집 문장은 한국어로 크게. 상태·메타는 작은 영문 대문자(`OPEN NOW` `WALK 3분` `VERIFIED 2026.08`). 영문 배지에는 한국어 `aria-label` |
| **색은 여섯, 일곱 번째는 없다** | 여섯 번째 Rust는 "접근성 근거 없음, 톤 때문"이라고 기록. "일곱이 되려는 순간 이 결정으로 거절하라" |
| **점 하나** | 워드마크 마침표·목록 불릿·지도 마커·저장 표시가 같은 뜻이라 한 파일에서 그림. 둥근 것이 전부 점은 아님 |

영문 UI는 이름표·상태·수치 세 목소리로만 나눴고, 셋을 가르는 건 크기가 아니라 **자간**입니다.

## 4. Honest Data — 화면이 거짓말하지 않게

- **모르는 값은 `NULL`입니다.** 가격을 모르면 0원이 아닙니다.
- 필드마다 **출처와 확신도**를 붙이고, 확신도가 낮은 값은 추천 계산에서 뺍니다.
- 문장도 단정하지 않습니다: "쉬는 날이에요" → "~로 알고 있어요. 확실하지 않으니 확인해 보세요"

## 5. Working with AI Agents

```text
진단 → 결정(나) → 지시서(프롬프트 에이전트) → 개발(코딩 에이전트) → 배포 → 재진단
```

- 지시서를 쓰는 에이전트는 **아홉 라운드 동안 여덟 번 틀렸고**, 여덟 번 모두 개발 쪽이 수치로 바로잡았습니다.
- 서비스를 지킨 것은 구조였습니다. **재는 쪽과 고치는 쪽을 나누고, 반박할 통로를 열어 두었습니다.**
- 자세한 이야기는 아래 기록 글 「진단을 그대로 받아 적은 지시서는 아홉 라운드 동안 여덟 번 숫자가 틀렸습니다」에 있습니다.

## 6. Stack

| 영역 | 선택 |
| --- | --- |
| 구조 | npm 워크스페이스: Next.js 웹 · Fastify API · 공유 Zod 스키마 |
| 데이터 | PostgreSQL, **ORM 없이** SQL 직접. 적용된 마이그레이션이 바뀌면 실행 거부 |
| 로직 | 도메인 로직은 전부 API에. 코스 엔진은 DB 없이 테스트되는 순수 함수 |
| 웹 | 서버 컴포넌트만. 브라우저가 API를 직접 부르지 않음 |
| 테스트 | 단위 198개 + Chrome DevTools Protocol로 직접 돌린 E2E. 첫 화면 무게도 테스트로 잠금 |
| 배포 | `main` push → 웹훅 → 서버 빌드 → 컨테이너 재시작 |

## Takeaways

- **기능보다 중심입니다.** 가장 큰 결정은 무엇을 더할지가 아니라 어디에 설지였습니다.
- **결정에는 뒤집을 조건을 같이 적습니다.**
- **AI의 진단은 출발점이고, 숫자는 직접 잽니다.**
